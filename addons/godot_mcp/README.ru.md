# Godot MCP Native (Протокол контекста модели)

[English Version](README.md)

![Версия Godot](https://img.shields.io/badge/Godot-4.x-blue?logo=godot-engine)
![Лицензия](https://img.shields.io/badge/License-MIT-green)
![Версия](https://img.shields.io/badge/Version-1.0.0-orange)

Мощный плагин для Godot Engine, который интегрирует AI-ассистентов (например, Claude) через Model Context Protocol (MCP). Позволяет AI читать и изменять проект Godot на естественном языке: сцены, скрипты, узлы и ресурсы.

## 🚀 Возможности

- **Полный доступ к проекту**: AI-ассистент может читать и изменять скрипты, сцены, узлы и ресурсы
- **Нативная реализация**: без зависимости от Node.js, все работает внутри Godot
- **Редактирование в реальном времени**: предложения AI можно сразу применять в редакторе
- **Полный набор инструментов** (50+):
  - **Инструменты узлов** (16): создание, изменение, управление узлами, копирование, перемещение, переименование, сигналы, группы
  - **Инструменты скриптов** (9): редактирование, анализ, создание, прикрепление, проверка GDScript, поиск по файлам
  - **Инструменты сцен** (6): работа со структурой сцен и сохранение
  - **Инструменты редактора** (8): управление редактором, скриншоты, проверка сигналов, перезагрузка файловой системы
  - **Инструменты отладки** (6): отладка, логирование, очистка логов, выполнение скриптов
  - **Инструменты проекта** (5): доступ к настройкам проекта и спискам ресурсов

## 📦 Установка

### Способ 1: Asset Library (рекомендуется)
1. Откройте проект в Godot
2. Перейдите на вкладку **AssetLib** в редакторе
3. Найдите "Godot MCP Native"
4. Нажмите **Download**, затем **Install**

### Способ 2: Ручная установка
1. Скачайте или клонируйте репозиторий
2. Скопируйте папку `addons/godot_mcp` в директорию `addons/` вашего проекта
3. Откройте проект в Godot
4. Перейдите в **Project > Project Settings > Plugins**
5. Включите плагин "Godot MCP Native"

## 🔧 Использование

### Включение плагина
1. Откройте **Project > Project Settings > Plugins**
2. Найдите в списке "Godot MCP Native"
3. Установите статус **Enable**

### Настройка MCP-сервера
Плагин предоставляет два транспортных режима.

#### HTTP-режим (для удаленного доступа)
- Подходит для: сетевой AI-интеграции
- Настройка: установите `transport_mode = "http"` и задайте `http_port` (по умолчанию: 9080)
- Опционально: включите `auth_enabled` и задайте `auth_token` для безопасности

### Подключение Claude Desktop

#### Конфигурация HTTP-режима
Отредактируйте конфиг Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "godot-mcp": {
      "url": "http://localhost:9080/mcp"
    }
  }
}
```

С аутентификацией:
```json
{
  "mcpServers": {
    "godot-mcp": {
      "url": "http://localhost:9080/mcp",
      "headers": {
        "Authorization": "Bearer your-secret-token-here"
      }
    }
  }
}
```

## 💬 Примеры запросов

После подключения вы можете взаимодействовать с проектом Godot через Claude:

```text
@mcp godot-mcp read godot://script/current

Помоги оптимизировать код перемещения игрока и предложи улучшения.
```

```text

Добавь куб в центр сцены и создай камеру, направленную на него.
```


```text

```

## 📚 Доступные команды

### Инструменты узлов (16)
- `get-scene-tree` - получить структуру дерева сцены
- `get-node-properties` - получить свойства конкретного узла
- `create-node` - создать новый узел
- `delete-node` - удалить узел
- `update-node-property` - обновить свойства узла
- `list-nodes` - вывести узлы под родителем
- `duplicate-node` - дублировать узел и его потомков
- `move-node` - переместить узел к новому родителю
- `rename-node` - переименовать узел
- `add-resource` - добавить дочерний ресурсный узел (коллизия, меш и т.д.)
- `set-anchor-preset` - установить пресет якорей для Control-узлов
- `connect-signal` - подключить сигнал между узлами
- `disconnect-signal` - отключить сигнал
- `get-node-groups` - получить группы, в которых состоит узел
- `set-node-groups` - задать группы для узла
- `find-nodes-in-group` - найти все узлы в группе

### Инструменты скриптов (6)
- `list-project-scripts` - список всех скриптов
- `read-script` - чтение выбранного скрипта
- `modify-script` - изменение содержимого скрипта
- `create-script` - создание нового скрипта
- `analyze-script` - анализ структуры скрипта
- `get-current-script` - получить текущий редактируемый скрипт

### Инструменты сцен (6)
- `list-project-scenes` - список всех сцен
- `read-scene` - чтение структуры сцены
- `create-scene` - создание новой сцены
- `save-scene` - сохранение текущей сцены
- `open-scene` - открытие сцены
- `get-current-scene` - получить информацию о текущей сцене

### Инструменты проекта (5)
- `get-project-info` - получить информацию о проекте
- `get-project-settings` - получить настройки проекта
- `list-project-resources` - список ресурсов проекта
- `create-resource` - создать новый ресурс
- `get-project-structure` - получить структуру каталогов проекта

### Инструменты редактора (5)
- `get-editor-state` - получить текущее состояние редактора
- `run-project` - запустить проект
- `stop-project` - остановить запущенный проект
- `get-selected-nodes` - получить выбранные узлы
- `set-editor-setting` - изменить настройки редактора

### Инструменты отладки (5)
- `get-editor-logs` - получить логи редактора/рантайма
- `execute-script` - выполнить выражение GDScript
- `get-performance-metrics` - получить данные производительности
- `debug-print` - вывести отладочное сообщение
- `execute-editor-script` - выполнить скрипт GDScript в контексте редактора

## 🔒 Рекомендации по безопасности

- ✅ **Продакшен**: всегда включайте аутентификацию (`auth_enabled = true`)
- ✅ **Токен**: используйте сложный токен (>=16 символов, буквы, цифры, спецсимволы)
- ✅ **Хранение**: не коммитьте токены в систему контроля версий
- ⚠️ **Удаленный доступ**: используйте HTTPS (TLS/SSL) для сетевого подключения

## 📋 Требования

- Без дополнительных зависимостей (нативная реализация)
